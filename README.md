## 📝 หน้าลงทะเบียน

**ข้อมูลที่กรอก:**
- ชื่อ-นามสกุล
- เลข Account MT5
- ประเภทบัญชี (Standard / Standard Cent)
- จำนวนเงินที่ฝาก (USD)

**หลังลงทะเบียน:**

- บันทึกข้อมูลลง Google Sheet

## 📊 หน้ารายงาน Port (Power Zone Report)

Dashboard แสดงผลการเทรดแบบ Real-time เชื่อมต่อ Google Sheets ผ่าน GAS

**ภาพรวมวันนี้:**
- จำนวนออร์เดอร์ทั้งหมด (TP / SL / เปิดอยู่)
- Win Rate และ Net Profit รวมทุก Slave
- กราฟกำไร/ขาดทุนรายวัน (7 วันย้อนหลัง)
- กราฟกำไรสะสม (Cumulative Profit)
- สัดส่วนกำไรแต่ละ Slave วันนี้
- ตารางออร์เดอร์ที่เปิดอยู่ (Floating P/L)
- ประวัติเทรดย้อนหลัง 100 รายการ

**บัญชีลูกค้า:**
- Master Account — Balance / Equity / Status
- Slave Accounts — แสดงทุกบัญชี พร้อม Win Rate / กำไรวันนี้
- รองรับทั้ง Standard (.tpx) และ Cent (.tpxc)

**ฝาก / ถอน:**
- สรุปยอดฝาก-ถอนในช่วงที่เลือก
- กราฟ Deposit / Withdraw รายวัน
- ตารางประวัติธุรกรรมทั้งหมด

**ฟีเจอร์:**
- กรองช่วงเวลาได้ (วันนี้ / เมื่อวาน / 7 วัน / เดือน / ปี / กำหนดเอง)
- LIVE badge — ดึงข้อมูลจาก GAS ทุกครั้งที่เลือกช่วงเวลา
- เข้าได้เฉพาะคนที่มีลิงก์ (noindex)
